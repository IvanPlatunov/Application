# Application

Клиент-серверное приложение на Python с разделением ответственности (MVC-подобная архитектура).

## 📋 Описание

Приложение демонстрирует грамотную архитектуру с четким разделением на слои:
- **Controllers** — обработка запросов и бизнес-логика
- **Models** — структура данных
- **Services** — вспомогательные операции
- **Views** — отображение данных
- **Utils** — утилитарные функции

## 🚀 Установка и запуск

Клонировать репозиторий:
git clone https://github.com/IvanPlatunov/Application.git
cd Application

Установить зависимости:
pip install -r requirements.txt

Запустить приложение:
python main.py

## 📁 Структура проекта

Application/  
├── controllers/    # Обработка запросов  
├── models/         # Модели данных  
├── services/       # Бизнес-логика  
├── views/          # Отображение  
├── utils/          # Утилиты  
└── main.py         # Точка входа

## 🛠 Технологии

- Python
- MVC-архитектура
- Разделение ответственности (Separation of Concerns)

## 📝 Особенности

- Четкое разделение слоев приложения
- Переиспользуемые компоненты
- Чистый и поддерживаемый код
