Клиент-серверное приложение на Python, построенное на принципах MVC-архитектуры.

---

## 📋 Описание

> **Проект** является надежным шаблоном для создания сложных сетевых приложений. Главная цель проекта — показать, как правильно организовать код, чтобы система была масштабируемой, легко тестируемой и поддерживаемой.

### 🎯 Что делает и для чего нужен
Приложение реализует полноценное сетевое взаимодействие между клиентом и сервером. Серверная часть принимает входящие запросы, маршрутизирует их через контроллеры, обрабатывает бизнес-логику в сервисном слое и возвращает клиенту структурированные данные. 

Благодаря грамотному разделению ответственности, добавление новых функций не ломает существующую логику, а работа с сетью и данными полностью изолирована от интерфейса.

### 🏗️ Архитектура
Архитектура четко разделена на следующие слои:

| Слой | Ответственность |
| :--- | :--- |
| 🎛️ **Controllers** | Прием, валидация и маршрутизация входящих запросов |
| 🗄️ **Models** | Описание структуры данных и взаимодействие с хранилищем |
| ⚙️ **Services** | Инкапсуляция основной бизнес-логики |
| ️👁️ **Views** | Форматирование и подготовка данных для отправки клиенту |
| 🛠️ **Utils** | Вспомогательные функции, логирование и утилиты |

##  Установка и запуск

**1. Клонировать репозиторий:**
```bash
git clone https://github.com/IvanPlatunov/Application.git
cd Application
```

**2. Установить зависимости:**
```bash
pip install -r requirements.txt
```

**3. Запустить приложение:**
```bash
python main.py
```

