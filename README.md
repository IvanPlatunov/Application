---

##  Описание

> **Application** — это полноценное сетевое приложение для управления пользователями и отслеживания валютных курсов. Проект демонстрирует грамотную организацию кода с четким разделением ответственности между слоями.

### 🎯 Что делает и для чего нужен
Приложение реализует систему учета пользователей и работы с валютами:
- **Управление пользователями** — создание, хранение и связь пользователей с валютами
- **Валютные курсы** — получение актуальных данных о валютах через внешнее API
- **Сетевое взаимодействие** — клиент-серверная архитектура для распределенной работы

Благодаря MVC-архитектуре, добавление новых функций (например, новых валют или типов пользователей) не требует изменения существующей логики.

### 🏗️ Архитектура проекта

| Слой | Файлы | Ответственность |
| :--- | :--- | :--- |
| 🎛️ **Controllers** | `server_controller.py` | Обработка входящих запросов, маршрутизация, координация между слоями |
| 🗄️ **Models** | `user.py`, `currency.py`, `author.py`, `user_currency.py`, `app.py` | Описание сущностей: пользователи, валюты, авторы и связи между ними |
| ⚙️ **Services** | `currency_service.py` | Бизнес-логика работы с валютами, обработка данных |
| 🌐 **Utils** | `currencies_api.py` | Интеграция с внешним API для получения курсов валют |
| 👁️ **Views** | `views/` | Форматирование и отображение данных для клиента |

### 🔄 Жизненный цикл запроса

```
Клиентский запрос
    ↓
🎛️ Server Controller (прием и маршрутизация)
    ↓
⚙️ Service Layer (бизнес-логика)
    ↓
🌐 External API (получение курсов валют, если нужно)
    ↓
🗄️ Models (работа с данными пользователей и валют)
    ↓
👁️ Views (формирование ответа)
    ↓
📤 Response (ответ клиенту)
```

## 🚀 Установка и запуск

**1. Клонировать репозиторий:**
```bash
git clone https://github.com/IvanPlatunov/Application.git
cd Application
```

**2. Установить зависимости:**
```bash
pip install -r requirements.txt
```

**3. Запустить приложение:**
```bash
python main.py
```

##  Технологии

- **Язык:** Python 3.10+
- **Архитектура:** MVC (Model-View-Controller)
- **Паттерн:** Разделение ответственности (Separation of Concerns)
- **Сеть:** Клиент-серверное взаимодействие
- **Внешние API:** Интеграция с сервисами валютных курсов

## ✨ Особенности

- ✅ **MVC-архитектура** — четкое разделение на контроллеры, модели, сервисы и представления
